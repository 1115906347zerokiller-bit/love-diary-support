隐私政策

更新及生效日期：2026年11月3日。适用于当前 LoveDiary 0.3.1 测试版本。

本地记录

应用无需注册或登录。你填写的姓名、关系日期、序言、日记、标签、草稿、照片及设置保存在设备本地，用于展示和管理你的记录。当前应用没有开发者运营的内容后台，不将上述内容发送给开发者。

照片与文件

只有你主动使用系统照片或文件选择器选择的内容会被导入，用于日记、头像或合照。应用不扫描或上传整个相册，不使用这些照片进行人脸识别。

数据收集与共享

当前版本不包含广告、追踪或第三方统计 SDK，不出售用户数据，不向广告商分享日记或照片。应用使用 Apple 系统框架及项目自有模块。

存储与删除

当前未提供 iCloud 同步或完整备份恢复。你可在应用内编辑或删除内容；删除日记会进入回收站。删除照片引用不等于立即彻底清除所有已保存原件。卸载应用可能删除应用容器内数据，系统备份和设备存储由你及 Apple 系统设置管理。请保留重要资料副本。

支持邮件与系统服务

如果主动联系支持，我们会收到你发送的邮箱、问题描述与附件，仅用于答复和处理问题；请避免附上私人记录。TestFlight、App Store 与系统诊断由 Apple 按其政策处理，你可在系统设置中管理诊断分享。本网站由 GitHub Pages 托管，无广告、分析脚本或跟踪 Cookie；访问日志及基础连接信息由 GitHub 按其隐私政策处理。

儿童与政策更新

本应用并非专为儿童设计。当前无注册与在线社交。若后续加入云同步或其他改变数据处理的功能，我们将更新本政策及相关说明。
